# 🔐 Password Manager App

A **secure, modern, and offline-first password manager** built with Flutter.
Designed with a strong focus on **privacy, security, and user experience**, this app allows users to safely store and manage their credentials locally on their device.

---

## 🚀 Features

* 🔐 **Local Encryption**
  All passwords are encrypted before being stored in the local SQLite database.

* 👆 **Biometric Authentication**
  Secure access using fingerprint or Face ID.

* 📂 **Smart Categorization**
  Organize credentials into categories such as:
  *Social, Work, Banking, Personal, Entertainment, Other*

* 🔍 **Advanced Search**
  Instantly find accounts by name, website, or notes.

* 🌙 **Modern UI (Material 3)**
  Clean and responsive design with smooth animations and customizable theme.

* 🌍 **RTL & Arabic Support**
  Full right-to-left layout support for Arabic users.

* 💾 **Offline First**
  No internet required. All data is stored locally on the device.

* 🔒 **Auto Lock Security**
  App automatically locks when sent to background for extra protection.

## 🛠️ Tech Stack

* **Flutter** – Cross-platform mobile framework
* **Dart** – Programming language
* **sqflite** – Local database
* **local_auth** – Biometric authentication
* **flutter_secure_storage** – Secure storage
* **crypto** – Custom encryption (XOR + Base64)
