# pass_manager
# مدير كلمات المرور 🔐

تطبيق آمن لإدارة كلمات المرور مع تشفير محلي ومصادقة بيومترية.

## المميزات ✨

- **تشفير محلي** - جميع كلمات المرور مشفرة قبل التخزين
- **مصادقة بيومترية** - دعم بصمة الإصبع و Face ID
- **تصنيفات ذكية** - تنظيم كلمات المرور في فئات (عمل، بنوك، تواصل اجتماعي، ...)
- **بحث سريع** - بحث فوري بين جميع كلمات المرور
- **واجهة حديثة** - تصميم Material You مع ثيم قابل للتخصيص
- **قاعدة بيانات محلية** - استخدام SQLite للتخزين الآمن

## التقنيات المستخدمة 🛠️

- Flutter 3.41.4
- Dart 3.4.1
- SQLite (sqflite)
- Local Authentication
- Custom Encryption (XOR + Base64)

## المتطلبات 📱

- Android 6.0 (API 23) أو أحدث
- iOS 11.0 أو أحدث (للأجهزة التي تدعم Face ID)
